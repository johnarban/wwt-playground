WWT examples

The base for these examples comes from the CosmicDS Vue Template, heavily modified to use Vite, as well as updated version of Vuetify and Vue.

    The blank WWT project demonstrates using WWT with Vite and merges (in an opinionated way) the linting that is default on the vue-ds-template and the defaults from a project created with npx init vuetify. Demonstrates a true cross-fade using the SPHEREx all sky Star and Line emission images. by true cross-fade where the total opacity at the midpoint is 100%, as opposed to a linear cross-fade where in the middle the total opacity is 75% (100% - 50%×50%). Demonstrate loading a 3D fits cube into WWT. This project uses a hack to trick the WWT engine into dispalying the appropriate data plane by manually paging through the FITS data. It only works for PPV oriented cubes, with a TAN projection, and really seems to need a properly formatted FITS header Test adding shaders to WWT. This will (or does) have an atmosphere shader. and maybe a ground image shader? Position an image in WWT, and get a WTML for it. Load the 13CO cube, a 2D Orion image, or your own FITS file, and step through the cube's velocity planes with a slider. Range, scale, colormap, and opacity are adjustable. 457 named stars from the HYG catalog as a spreadsheet layer, colored by B−V and sized by magnitude, with labels on the brightest. Search for an object by name, or click the sky to identify the nearest object with SIMBAD. Clicking doesn't work so well - need to figure out how to get reasonable answers from SIMBAD.
